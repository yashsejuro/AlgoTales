# 🚀 AlgoTales — Interactive DSA Storyboard

> Learn Data Structures & Algorithms like a story, not a struggle.

AlgoTales is an interactive web platform that transforms complex DSA concepts into engaging visual stories. Instead of memorizing algorithms, users experience them step-by-step through animations, controls, and real-time feedback.

---

## ✨ Features

### 🎯 Core Concepts Covered

* Binary Search
* Stack (LIFO)
* Linked List
* Binary Tree (Traversals)

### 🎮 Interactive Learning

* ▶️ Play / ⏸️ Pause / 🔄 Reset controls
* ➡️ Step-by-step execution
* ⏳ Time-travel slider (navigate between steps)

### 🧠 Smart Visualizations

* Dynamic animations for each algorithm
* Highlighting active elements
* Smooth transitions for better understanding

### 💻 Code Sync Mode

* Real-time code highlighting
* Step → Code mapping

### 🧩 Custom Input Playground

* Input your own data
* Visualize algorithms with custom values

### 🧠 POV Mode (Unique)

* Algorithm "thinking" via speech bubbles
* Makes logic feel human and intuitive

### 🎭 Story Mode

* Each step explained like a story
* Inspired by Panchatantra-style learning

## 🧠 How It Works

Each algorithm is broken down into steps:

1. Initial state is created
2. Each step is stored in a sequence
3. UI renders based on current step index
4. Controls allow navigation through steps

This ensures:

* Predictable animations
* Easy debugging
* Smooth user interaction
